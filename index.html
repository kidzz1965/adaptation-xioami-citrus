POCO M3 Droidian APT Repository

1. Add GPG key

curl https://kidzz1965.github.io/adaptation-xioami-citrus/citrus-repo.gpg | sudo tee /etc/apt/trusted.gpg.d/citrus.gpg

2. Add repository

echo "deb https://kidzz1965.github.io/adaptation-xioami-citrus stable main" | sudo tee /etc/apt/sources.list.d/citrus.list
sudo apt-get update

3. Install adaptation

sudo apt-get install adaptation-xiaomi-citrus
